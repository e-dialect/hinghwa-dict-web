# 亲戚计算数据补全（Phase 1）

本轮继续使用原有按节点名称查表的十种关系字段，不替换计算算法。两端数据语义相同，从 85 个关系节点补至 110 个，696 条有向关系引用均指向已登记节点。分阶段升级计划见 [Issue #188](https://github.com/e-dialect/hinghwa-dict-web/issues/188)。

## 来源与边界

- 用户提供《莆仙话亲属称谓关系图 v1.0（莆田腔版本）》，莆仙乡音社，2026-02-01。原附件：[关系图](https://github.com/user-attachments/assets/3aacc81d-7607-45d6-815c-7721fdf7c905)。图中普通话角色、家系连线及内外孙区分用于增量修正，不据模糊字形推造方言词条。
- 用户提供只读词库快照“兴化语记当前数据.sqlite3”，核查表 `word_word` 的 ID、word、definition。这是提供的快照，不声称其等于线上实时词库。
- 旧数据的关系名称与已登记家系边用于补足缺失目标。新增关系节点的 `note` 给出普通话角色定义；未绑定词条均明示“兴化语称谓待核”。角色占位文字不作为已确认方言词形。

## 关系修正

- 甥男、甥女的父母原来倒置，改为父=姊夫/妹夫、母=姊亲/妹亲。
- 姨姊妹的配偶改用夫字段。
- 表兄弟、表姊妹父母选项包括姑、舅、姨三路；“姑丈”“姨丈”作为词形不再误用为关系节点名。
- 孙女之子女的父=孙婿、母=孙女。
- 外孙的兄弟姊妹、配偶、后代沿外孙分支，不再切换至内孙。外孙妇、外孙婿、外曾孙、外曾外孙各有独立节点，其中未确定兴化语称谓者显示待核。
- 外曾祖父母的子女边改接外祖父及其兄弟姊妹，避免接入祖父家系。
- 祖母母家父母“曾外祖父母”与外祖父家系“外曾祖父母”保留不同节点，避免因名称近似合并家系。
- 原 20 个缺失的真实关系目标补为有定义的节点，额外补充外孙配偶/后代与曾孙女共 5 个节点。

## 页面必要修正

两端初始词条直接加载，异步请求只允许当前关系写入结果，保持词条声明顺序。API 失败保留原 ID 并提供重试，不误报缺词。角色占位提示实际词形仍待核，不是正式词条。所有结果保留通用投稿邀请：“还有更多说法，或把纸面说法整理为正式词条”，不将投稿局限于当前缺词。页面明确说明投稿只进入词库，审核后仍需维护者手动关联亲戚计算器；本轮未打通自动关系更新。uni 页面使用 `getWordDetails` 的扁平返回值，公共列表通过可选状态及邀请属性区分显示，不改变其他页面的默认投稿提示。关系候选未选定时阻止继续计算，返回操作不能弹空初始栈。排行和限定称谓提示展示在页面。

## 未确定与后续阶段

- 20 个不同的旧方言词形仍未在快照中找到精确对应：姆妈、伯妈、阿姆、姑妈、姑丈公、姨丈公、老父、阿爸、阿负、阿奶、阿嫡、娘奶、阿妸、依妸、妈妈、妈阿、阿弟妇、表兄弟、大伯、阿妗囝。新增角色占位不计入这份方言清单。
- 大囝/长子和细囝/尾囝有排行条件；阿姨囝只确认妻妹，现有姨姊妹节点合并妻姊与妻妹。页面明确提示限定条件，本轮未建立排行状态。
- 聚合的堂/表亲节点和候选数组仍会丢失具体来源人身份；选择父母时只表示可能角色，不能保证父母来源保持配对。性别、内外孙及世代未完全细分。补图完整不等于任意关系路径语义全正确。
- 部分旧方言词形、祖辈复用词条仍待独立方言校订；本轮未声称完成整个旧数据语言学审计。
- 义亲、继亲及亲属合称缺少现有十字段的明确入口，留给后续数据结构/模块更新阶段，不添加不可达节点。
- 经维护者确认，兴化语记继续沿用旧版计算器，本轮只补数据与必要加载保护。版本化关系数据、新引擎及投稿到关系映射的闭环留到乡声集盒未来实施；本轮不提交这些结构/模块升级 PR。

## 验证

不需要第三方依赖：

```sh
node scripts/check-relative.mjs
# 同时核对另一端（按实际 checkout 位置传入）
node scripts/check-relative.mjs ../hinghwa-dict-uni-app
```

uni 仓库对应第二条使用 `../hinghwa-dict-web`。脚本检查节点唯一、十字段、引用完整、词条占位、关键路径/父母性别/ID约束、两端深比较，以及真实组件 watcher 的异步竞态、API 失败、null ID、初始栈保护。构建/页面检查另行记录交付结果；脚本不声称覆盖全部语言学关系。
