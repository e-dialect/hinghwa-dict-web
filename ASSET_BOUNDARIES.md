# Asset and Data Boundaries / 资产与数据边界

The root AGPL declaration covers authorized software code, not every file or
piece of content presented by the application.

| Path or material | Boundary |
| --- | --- |
| `src/components/Tools/relative.js` | Project-original compilation and relationship mapping, as confirmed by the maintainer on 2026-09-16. Individual kinship terms are language facts; the compilation's inclusion does not turn language content into AGPL-covered software. |
| `public/certificate.png` | Puxian proficiency-certificate illustration purchased for project use, as confirmed by the maintainer on 2026-09-16, together with project/seal artwork. It remains outside the code license and grants no trademark or standalone media right. |
| `public/favicon.svg`, `src/assets/blue.svg`, `src/assets/white.svg` | Project/product identity artwork. No trademark right or endorsement is granted by the code license. |
| `src/assets/rewards.svg` | Purchased illustration authorized for project use, as confirmed by the maintainer on 2026-09-16. It is excluded from the root software license; no standalone media redistribution or alternative-commercial-relicensing grant is implied beyond its purchase terms. |
| Runtime dictionary, article, quiz, music, account, and recording content | Content returned by the backend or supplied by users requires its own provenance, consent, privacy basis, and license/permission. |

Before adding content, recordings, screenshots, fonts, or design assets, record
the source, rightsholder, license/permission, attribution requirements, and any
privacy constraints. A code CLA does not automatically cover these materials.
